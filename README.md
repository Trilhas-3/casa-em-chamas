# 👨‍🚒 Herói das Chamas

Um jogo de aventura interativa feito com HTML. Você é um bombeiro que precisa explorar uma casa em chamas e encontrar uma criança para resgatá-la.

## Como jogar

Abra o arquivo `index.html` no navegador e escolha os caminhos pelos links. Explore os cômodos até encontrar a criança e concluir o resgate.

## Arquivos

- `index.html`: início do jogo.
- `sala.html`, `cozinha.html`, `banheiro.html` e páginas dos quartos: etapas da exploração.
- `fim-de-jogo.html`: tela de vitória.
